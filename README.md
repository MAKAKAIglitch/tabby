# Tabby — NeoForge port in progress

**Target: NeoForge for Minecraft 1.21.1.**

This branch is currently a porting workspace, not a release-ready NeoForge build. The source tree still contains Fabric entrypoints and Fabric API integrations; the native NeoForge ModDevGradle setup, mod entrypoint, event integration, configuration handling, and mixin/access-transformer migration have not yet been completed.

Do not treat a JAR from this branch as a working NeoForge release. The port will be marked ready only after a successful NeoForge build and a client startup test on Minecraft 1.21.1.
